👋 Hey, I'm Aditya
I'm a web developer working with PostgreSQL, Express.js, React, and Node.js. I'm now learning DevOps to understand the complete journey of an application—from a code change on my laptop to a service that users can depend on.
I'm following Imran Teli's Decoding DevOps course and using this repository to organise my notes, hands-on practice, troubleshooting, and interview preparation.
My goal is to understand why each tool is needed, how it works, and where it fits in software delivery.
My starting point	My direction
Building PERN applications	Deploying and operating them reliably
Working with application code	Understanding servers, networks, and infrastructure
Using Git in development	Automating checks and delivery workflows
Fixing issues during development	Diagnosing problems across environments
